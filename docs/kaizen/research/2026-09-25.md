## TL;DR

**The week's most consequential external item is a new AgentCore Runtime, and it lands on the one cost lane that has never had a lever.** AWS made a new Runtime generally available on 2026-09-18. You opt in with `platformVersion: V2`. It reclaims unused memory during a session, so a session **pays for the memory it actually uses, not its peak**. It also quotes a P75 cold start of **1.9–2.0 s against 5.4–30 s on V1**. Runtime memory is **73% of the AICC bill** (W5 in the queue). Every prior cost win has been on the token side, and the W5 "instance-based Runtime arithmetic" entry has gone five months with no proposal. Our `CfnRuntime` sets no `platformVersion`. Even `aws-cdk-lib` 2.270.0 has no typed property for it, so adopting V2 is an `addPropertyOverride` plus a dev A/B, not a bump.

**The most pressing internal signal is two small verified gaps in how we treat a finished model call.** (1) Both of our side-channel summarizers, the compaction summary and the tool-group summary, check a single stop reason (`max_tokens`). A refusal or guardrail stop therefore looks like success. For compaction, whatever text comes back becomes a checkpoint in the **cacheable history** of every later turn. (2) In the SPA, the loading state clears only when the socket closes, not on `done`. The Stop handler never checks for completion, so pressing Stop in the gap after `done` (a `session_title` can still be arriving then) writes an `interrupted` marker onto a turn that finished. Both fixes are small, and both are verified on disk.

**Recommended #1: A/B the V2 Runtime in dev.** It is the first item in five months that could move the largest line on the bill, and a dev A/B is cheap and reversible.

## External Scan

### What's moving this week

The week's shape: **the platform moved under the compute, and the protocol layer went quiet.** AWS shipped a new Runtime generation, Claude Opus 5.5, GPT-6 Sol and Luna, Grok 4.6 and two Managed-KB connectors, all inside five days. The MCP spec side did nothing normative: the revision is still 2026-07-28 and python-sdk had no release. Governance moved instead: **new SEPs now require a Working Group**, and SEP-2636 (Tool Manifests) was closed to go that route. That takes incremental tool-catalog sync off any near-term roadmap. Our tool-listing bloat work should stop waiting for it.

The second theme is **the same prompt-cache bug class, again.** Claude Code shipped five more "history re-sent slightly differently on resume" fixes (2.1.277–2.1.282). The triggers were a parallel tool-call turn, an interrupted tool-search result, a restart with a pending permission prompt, a dropped empty text block, and an MCP server disconnecting or still connecting. That last one maps directly onto our pre-flight path. When an MCP server fails its pre-flight `tools/list`, its tools drop out of `toolConfig`, which re-writes the prefix, and the prefix is re-written again when the server recovers. Separately, **Anthropic has a beta for mid-conversation tool changes** (`mid-conversation-tool-changes-2026-07-01`), which LangChain adopted this week. It sends tool additions and removals as appended blocks instead of rewriting the tool list. If Bedrock Converse ever carries it, it is the structural answer to "tools that appear after OAuth consent re-write a 30k–150k prefix". Bedrock support is unverified.

The third theme: **Strands is becoming a harness, not only an SDK.** `python/v1.57.0` (09-22) ships the Strands harness, `mcp_router` and `handoff_to_user` vended tools, and a Bedrock `requestTimeout`. An HN thread on the harness launch reached 146 points, and commenters were skeptical of its benchmark. For our pins 1.57 is non-breaking. It also carries the fix for the `InterventionRegistry` hole we flagged last week (#4371) and a no-mutate fix for tool-schema normalization (#4426), which is prompt-cache adjacent. The prompt-caching watch paid out one partial result: upstream now maps cache-write tokens for **Chat Completions** (#4361, merged 09-18). Our own helper only reads the Responses shape. Only one curated model (Qwen3 Coder, `apiMode: 'chat'`, no cache rates) runs that path today, so this is a correctness note, not a cost hole.
