## TL;DR

**The week's most consequential external item is the price of the V2 AgentCore Runtime, and it changes the shape of last week's #1.** AWS published the V2 rates: **$0.0169/GB-hour of memory against V1's $0.00945, which is 1.79×**, and $0.1276/vCPU-hour against $0.0895 (1.43×). Idle memory is reclaimed after 120 s, and a committed-baseline tier ($0.0132/GB-hour) is "launching by October 2026". V2 therefore saves money only if our billed GB-hours fall **below ~56% of V1's**. That is plausible, because V1 bills an idle microVM at its peak for the whole 900 s idle timeout. But it is a measurement to make, not a given. In the same week `aws-cdk-lib` 2.272.0 added a typed `CfnRuntime.platformVersion`, which retires the plan's `addPropertyOverride`. Step 1 of the merged V2 plan, the deploy-script allow-list fix (B1), has still not been started.

**The most pressing internal signal is that the nightly has been red for two nights and will stay red until someone acts.** On 10-01 the teardown of the ephemeral `nightly-develop-PlatformStack` failed because the AgentCore Runtime timed out while deleting (`NotStabilized`). The stack is now in `DELETE_FAILED`, so the 10-02 deploy could not update it. No upstream report matches.

**Recommended #1: re-base the V2 plan on the published price, and land its B1 deploy-script fix.** Without that fix the dev A/B cannot be run cleanly, and the price now decides whether the A/B is worth running at all.

## External Scan

### What's moving this week

The week's shape: **the model layer moved again, and two of its moves are about history, not capability.** Claude Sonnet 5.5 shipped (09-28, Bedrock `global.*`), and Sonnet 4.5 was deprecated for 2026-11-30. Opus 5.5, which we curated on 09-26, has thinking that cannot be turned off. Our compaction and tool-result offloader both rewrite history. Nobody has run a compaction turn on Opus 5.5.

Sonnet 5, Sonnet 4.6 and the 4.5 models return 400, and the examples use the InvokeModel body, not Converse. That rules it out for our default Haiku path and probably for Strands today. It is still the first time the structural fix for "tools that appear mid-session re-write the prefix" has been reachable on Bedrock at all.

### 1. Re-base the V2 Runtime plan on the published price, land B1, and use CDK's typed `platformVersion`

- **Source**: https://aws.amazon.com/bedrock/agentcore/pricing/ (verified 2026-10-02); `aws-cdk-lib` 2.272.0; queue ▸ [2026-09-25] V2 A/B; `docs/specs/agentcore-runtime-v2.md`.
