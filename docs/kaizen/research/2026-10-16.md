## TL;DR

**The week's most consequential external item is that Claude Haiku 5.5 now has Bedrock prices, and they are tiered.** The Price List API carries 20 SKUs for it in us-west-2. Up to 100K prompt tokens, Regional is **$0.11 / $0.55 per MTok**, exactly a tenth of our Haiku 4.5 default. Above 100K every bucket costs **5× more**. Our `CuratedModel` holds one flat rate per bucket, and model-relative compaction cuts at a fraction of a 1M window. ## External Scan

### What's moving this week

A quiet week upstream and a loud one in pricing. AWS moved two cost assumptions under us at once. Haiku 5.5's Bedrock rates landed with a 100K price step. AgentCore Memory short-term storage switched from a flat $0.25 per 1,000 events to consumption billing (ingest, **retrieval** and storage per GB). Neither change needs code to keep working, but both change what the cheapest correct configuration is. Both are the kind of change our cost math absorbs silently, at the wrong number, unless someone writes it down.

Strands shipped three releases (1.60.0 → 1.61.1). None breaks us, and the caching watch is clear: #4618 has not moved since 09-28, and Bedrock usage is still disjoint at 1.61.1. The interesting part is **convergence**. 1.61.1's #5166 drops unsigned reasoning blocks for Claude inside `BedrockModel._format_bedrock_messages`, which is the fix we wrote ourselves on 10-15 (`29b05de1`), plus the reverse direction we don't handle (signed Claude reasoning replayed to GPT/Nova). On the multi-agent side, Strands is pulling agent-composition tools into the SDK: a vended `subagent` tool (1.59.0) replaces the tools repo's `use_agent`, and a vended `swarm` merged on 10-16 but has not been released. Claude Code and Anthropic's Managed Agents both shipped compaction and orchestration patterns (idle compaction before the 1h cache expires; `multiagent_20261001` phased workflows) that map directly onto our compaction and handoff specs.

### Patterns worth considering

- **Price tiers inside one model.** Haiku 5.5 (100K), GPT-6 Astra (272K), and Gemini-class long-context tiers all charge more past a prompt-size boundary. It is becoming the norm for 1M-window models, not an Astra quirk.
  - **Where**: the Price List SKUs above; the 10-03 Astra decision in `decisions.md`.
  - **Fit**: one optional `priceTiers: [{ aboveInputTokens, rates }]` on `CuratedModel`, read by `CostCalculator`, closes both. Without it, the safe rule is to cap `maxInputTokens` at the boundary, which also keeps compaction below it.
  - **Verdict**: **Worth trying** (folded into Top 5 #1).
- **Compact at the cache cliff, not after it.** Claude Code compacts an idle large conversation just before its 1h cache expires, so the return message pays for a small prefix instead of re-writing a large one.
  - **Where**: Claude Code 2.1.299.
  - **Fit**: our default TTL is 5 minutes, so the cliff is reached on almost every pause, and a pre-emptive compaction call while the user is away is a cost the user may never repay. It may fit the 1h static-prefix arm only.
  - **Verdict**: **Monitor.** Measure first with the dashboard's cliff data; don't build on a vendor pattern tuned for a different TTL.
- **The SDK owns cross-model history hygiene.** Strands #5166 makes reasoning-block filtering per model a formatter concern.
  - **Fit**: retires our projection and covers the direction we don't.
  - **Verdict**: **Worth trying** (Top 5 #2).

## Take

The system is trending **toward** the ecosystem on the SDK side, where Strands keeps absorbing things we hand-built (reasoning hygiene this week, cache-write mapping already pinned and not yet harvested). It is trending **away** from it on pricing, where AWS's models increasingly charge by tier and by byte while our catalog and cost model assume one flat rate per bucket. The one change that would matter most is a priced Haiku 5.5. It is about a tenth of the default's cost, and it has been one probe away for two weeks. The first thing Phil would notice if it shipped is the per-session cost column on the admin dashboard dropping by an order of magnitude for ordinary conversations. That only holds if the row is declared so that long turns can't hide in the 5× tier.
