## External Scan

### What's moving this week

The week is about **harnesses learning to spend less at the cache boundary.** Claude Code 2.1.314 compacts an idle >200K-token conversation so the first message after the TTL lapses is cheap; opencode added a percentage compaction buffer; a widely read gist showed Claude Code's background-agent summary calls costing 8–20% of one user's spend, with the ~2% that miss the cache carrying over a third of it. All three are our prompt-cache contract seen from outside. LibreChat 0.8.9-rc1 shipped Projects, MCP Apps, remembered approvals and deferred MCP OAuth, the nearest feature-set comparison to ours.

Platform SDKs moved faster than our pins: `bedrock-agentcore` is at 1.25.2 (we pin 1.24.2); MCP python-sdk 2.3.0 shipped Oct 2 and Strands' `mcp<2.2` cap blocks it; FastMCP moved to the PrefectHQ org and shipped an alpha for skills over MCP. Anthropic donated the Agent Skills spec to the Agentic AI Foundation. No new model launches.
