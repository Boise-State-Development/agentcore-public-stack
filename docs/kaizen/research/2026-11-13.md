## External Scan

### What's moving this week

**The platform is absorbing the glue again, this time around the Runtime.** V2 is now the default for new Runtimes (P75 start under 2 s against 29.7 s on V1), and its lifecycle hooks give snapshot preparation a documented phase, `memory` then `disk`, in place of the `/ping`-ordering trick we measured our way into on 2026-10-10. Web search became a single IAM call (`InvokeWebSearch`, $7/1K, six regions including us-west-2), with the SDK's `WebSearchClient` enforcing domain and date filters that a call can narrow but not widen. MCP's ext-apps v2.1.0 put the single-iframe relaxation (#717) in a tagged release, but `basic-host` still uses two iframes (#718 open).

**Harnesses converged on "code mode" and on keeping caches alive.** Claude Code 2.1.323, opencode 2.2.6 and Pydantic AI 2.67 all shipped variants of letting the model write code that calls tools, instead of one model round per call. opencode 2.2.7 times **prompt-cache warming from the model's cache TTL**, which is the 5-minute cliff our #1882 readout priced at 32.4% of prod spend. Claude Code fixed a compaction bug where `/compact` summarised away a user message the model hadn't answered yet, which is a cheap invariant for our cut too. Anthropic shipped Fable/Mythos 5.2. Nothing came ahead of re:Invent (Nov 30 – Dec 4).

### Patterns worth considering

- **Time cache warming from the cache TTL** (opencode 2.2.7).
