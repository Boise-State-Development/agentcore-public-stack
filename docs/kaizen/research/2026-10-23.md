## External Scan

### What's moving this week

The week's theme is **preserved thinking catching up with everyone's compaction**. Anthropic documents that the 5.5 generation (Fable 5.1, Opus 5.5, Sonnet/Haiku 5.5) rejects a replayed thinking block if anything before it changed. It enforces this by default for accounts created on or after 2026-08-31. Keep-tail compaction, which summarizes the head and keeps recent turns verbatim, trips it by construction. The responses converged within days. Strands added a one-retry `drop_block` fallback (#5171) and opened an epic for server-side compaction (`Model.compact()`, #5410/#5464, design 0022). Claude Code fixed compaction thrashing. pydantic-ai shipped append-only instructions and byte-stable restored histories, which is our prompt-cache contract nearly verbatim. Nobody is retiring client-side compaction yet, but the direction is "let the provider compact," and Anthropic's `compact-2026-09-04` is the endpoint everyone is pointing at.

AWS's week was quieter but practical. Claude structured outputs reached Bedrock (10-20), and AgentCore Gateway gained InvokeModel with ordered model fallback (10-22). Gateway fallback has no Converse support, so it is not usable from Strands yet. On the Price List, **GPT-6 Astra now appears** (16 SKUs), which makes a sentence in `CLAUDE.md` false. Upstream MCP had a quiet week: no spec release, no python-sdk release, and the ext-apps PRs we track are still open. FastMCP cut three patch releases, one of them prompted by a certificate-authority compromise.
