CAREER proposal audit: Publication and IP. Each criterion is pass, fail, cant_tell or not_applicable.

| name | title | type | find | enum |
|------|-------|------|------|------|
| open_access | Open access | enum | Publications will be made openly available (for example through NSF-PAR or open access journals). | pass, fail, cant_tell, not_applicable |
| data_formats | Data formats | enum | The Data Management Plan names the file formats the data will use. | pass, fail, cant_tell, not_applicable |
| metadata_standard | Metadata standard | enum | The Data Management Plan names a metadata standard. | pass, fail, cant_tell, not_applicable |
| code_sharing | Code sharing | enum | The proposal says how the project's code or models will be shared. | pass, fail, cant_tell, not_applicable |
| ip_rights | Intellectual property | enum | The proposal addresses who owns any inventions or intellectual property. | pass, fail, cant_tell, not_applicable |
| data_license | Data license | enum | The proposal names a license for the data it shares. | pass, fail, cant_tell, not_applicable |
| acknowledgement | NSF acknowledgement | enum | The proposal says publications will acknowledge NSF support. | pass, fail, cant_tell, not_applicable |
