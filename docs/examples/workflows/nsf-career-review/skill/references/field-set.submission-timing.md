CAREER proposal audit: Submission Timing. Each criterion is pass, fail, cant_tell or not_applicable.

| name | title | type | find | enum |
|------|-------|------|------|------|
| target_deadline | Target deadline named | enum | The proposal names the CAREER deadline or submission window it targets. | pass, fail, cant_tell, not_applicable |
| submitted_on_time | Submitted before the deadline | enum | The proposal was submitted on or before its deadline. A draft cannot show a submission time. | pass, fail, cant_tell, not_applicable |
| start_date_stated | Start date stated | enum | A requested start date for the award is stated. | pass, fail, cant_tell, not_applicable |
| start_date_lead_time | Start date leaves time for review | enum | The requested start date is at least six months after the target deadline. | pass, fail, cant_tell, not_applicable |
| duration_stated | Duration stated | enum | The requested award duration is stated in months or years. | pass, fail, cant_tell, not_applicable |
| timeline_matches_duration | Timeline matches the duration | enum | The project timeline covers the requested duration and schedules nothing after the award ends. | pass, fail, cant_tell, not_applicable |
| field_seasons_in_period | Field seasons inside the award | enum | Every field season in the timeline falls inside the award period. | pass, fail, cant_tell, not_applicable |
| annual_milestones | Annual milestones | enum | The timeline states at least one milestone for every project year. | pass, fail, cant_tell, not_applicable |
| new_or_resubmission | New or resubmission stated | enum | The proposal says whether it is a new submission or a resubmission. | pass, fail, cant_tell, not_applicable |
| internal_routing | Internal routing noted | enum | The proposal notes the date it was routed to the institution's sponsored programs office. | pass, fail, cant_tell, not_applicable |
