CAREER proposal audit: Summary and Description. Each criterion is pass, fail, cant_tell or not_applicable.

| name | title | type | find | enum |
|------|-------|------|------|------|
| summary_headings | Summary has the three headings | enum | The Project Summary has separate headings for Overview, Intellectual Merit and Broader Impacts. | pass, fail, cant_tell, not_applicable |
| summary_third_person | Summary in the third person | enum | The Project Summary is written in the third person (no 'we' or 'I'). | pass, fail, cant_tell, not_applicable |
| description_broader_impacts_section | Distinct Broader Impacts section | enum | The Project Description has a distinct section headed Broader Impacts. | pass, fail, cant_tell, not_applicable |
| integrated_education_plan | Integrated education plan | enum | The Project Description has an education plan that is integrated with the research, not a separate add-on. | pass, fail, cant_tell, not_applicable |
| prior_support_section | Results from Prior NSF Support | enum | The Project Description has a Results from Prior NSF Support section, or states the PI has had no NSF support in the past five years. | pass, fail, cant_tell, not_applicable |
| prior_support_merit_impacts | Prior support states merit and impacts | enum | If prior NSF support is reported, it states that award's Intellectual Merit and Broader Impacts. | pass, fail, cant_tell, not_applicable |
| research_objectives | Research objectives stated | enum | The Project Description states specific research objectives or hypotheses. | pass, fail, cant_tell, not_applicable |
| evaluation_plan | Evaluation plan | enum | The Project Description describes how the education activities will be evaluated. | pass, fail, cant_tell, not_applicable |
| references_cited_in_text | References cited in the text | enum | Works in References Cited are cited in the Project Description. | pass, fail, cant_tell, not_applicable |
