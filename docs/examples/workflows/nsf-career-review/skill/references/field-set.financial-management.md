CAREER proposal audit: Financial Management. Each criterion is pass, fail, cant_tell or not_applicable.

| name | title | type | find | enum |
|------|-------|------|------|------|
| pre_award_costs | Pre-award costs | enum | Any pre-award costs fall within 90 days before the start date. | pass, fail, cant_tell, not_applicable |
| cost_sharing_none | No voluntary cost sharing | enum | The proposal shows no voluntary committed cost sharing. | pass, fail, cant_tell, not_applicable |
| rates_basis | Rates follow the negotiated agreement | enum | The F&A rate is said to follow the institution's negotiated rate agreement. | pass, fail, cant_tell, not_applicable |
| escalation_stated | Salary escalation stated | enum | The budget justification states the annual salary escalation used. | pass, fail, cant_tell, not_applicable |
| tuition_handling | Tuition handled correctly | enum | Graduate student tuition is budgeted and excluded from the F&A base, or the proposal says none is charged. | pass, fail, cant_tell, not_applicable |
| unallowable_costs | No unallowable costs | enum | The budget contains no unallowable costs such as entertainment, alcohol or general office supplies. | pass, fail, cant_tell, not_applicable |
| program_income | Program income | enum | Any program income the project would earn is identified. | pass, fail, cant_tell, not_applicable |
