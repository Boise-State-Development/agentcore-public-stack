CAREER proposal audit: Cover Sheet. Each criterion is pass, fail, cant_tell or not_applicable.

| name | title | type | find | enum |
|------|-------|------|------|------|
| title_prefix | Title starts with CAREER: | enum | The proposal title begins with the prefix 'CAREER:'. | pass, fail, cant_tell, not_applicable |
| title_consistent | Title consistent | enum | The title is the same everywhere it appears. | pass, fail, cant_tell, not_applicable |
| pi_name_consistent | PI name consistent | enum | The PI's name is the same everywhere it appears. | pass, fail, cant_tell, not_applicable |
| institution_consistent | Institution consistent | enum | The institution's name is the same everywhere it appears. | pass, fail, cant_tell, not_applicable |
| amount_matches_budget | Requested amount matches the budget | enum | The total amount requested on the cover matches the cumulative budget total. | pass, fail, cant_tell, not_applicable |
| directorate_named | Directorate and program named | enum | The cover names the NSF directorate and program the proposal is submitted to. | pass, fail, cant_tell, not_applicable |
