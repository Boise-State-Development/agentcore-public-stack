CAREER proposal audit: Eligibility. Each criterion is pass, fail, cant_tell or not_applicable.

| name | title | type | find | enum |
|------|-------|------|------|------|
| pi_doctorate | PI holds a doctorate | enum | The PI holds a doctoral degree in a field supported by NSF, stated in the biosketch or departmental letter. | pass, fail, cant_tell, not_applicable |
| pi_untenured | PI is untenured | enum | The PI is untenured (for example an assistant professor), stated in the departmental letter or biosketch. | pass, fail, cant_tell, not_applicable |
| pi_tenure_track | Tenure-track position | enum | The PI holds a tenure-track (or tenure-track-equivalent) position at the submitting institution. | pass, fail, cant_tell, not_applicable |
| eligible_institution | Eligible institution | enum | The submitting organization is a US institution of higher education or other organization eligible for CAREER. | pass, fail, cant_tell, not_applicable |
| no_prior_career | No prior CAREER award | enum | The proposal or letter states the PI has not previously received a CAREER award. | pass, fail, cant_tell, not_applicable |
| submission_count | Fewer than three prior CAREER submissions | enum | The proposal states how many times the PI has submitted to CAREER before, and the number is fewer than three. | pass, fail, cant_tell, not_applicable |
| single_pi | Single PI | enum | The proposal lists exactly one PI and no co-PIs, as CAREER requires. | pass, fail, cant_tell, not_applicable |
| letter_confirms_eligibility | Letter confirms eligibility | enum | The departmental letter explicitly confirms the PI meets the CAREER eligibility requirements. | pass, fail, cant_tell, not_applicable |
