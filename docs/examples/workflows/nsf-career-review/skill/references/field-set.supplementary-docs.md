CAREER proposal audit: Supplementary Docs. Each criterion is pass, fail, cant_tell or not_applicable.

| name | title | type | find | enum |
|------|-------|------|------|------|
| departmental_letter | Departmental letter included | enum | A letter from the department head is included, as CAREER requires. | pass, fail, cant_tell, not_applicable |
| dmp_present | Data Management Plan included | enum | A Data Management and Sharing Plan is included and is at most two pages. | pass, fail, cant_tell, not_applicable |
| dmp_repository | DMP names a repository | enum | The Data Management Plan names the repository or archive where the project's data will be deposited. | pass, fail, cant_tell, not_applicable |
| letters_of_collaboration | Letters of collaboration in the standard form | enum | Any letter of collaboration states only the intent to collaborate, without endorsing the proposal. | pass, fail, cant_tell, not_applicable |
