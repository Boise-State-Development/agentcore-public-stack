Why the name had to grow

An assistant could hold instructions and a set of documents, and that was the whole of it. An agent keeps all of that and then composes the rest of the platform around it — a model, tools, skills, memory — with your role deciding what is on the table. Once the editor could do all of that, calling the result an "assistant" was underselling it.
